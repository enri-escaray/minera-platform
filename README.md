# Plataforma Minera

Software para operaciones mineras en entornos críticos y remotos: trazabilidad del mineral,
despacho, mantenimiento predictivo e integración ERP. Arquitectura edge + nube segmentada
según IEC 62443. **Empezá por `CLAUDE.md`** — es el mapa del proyecto.

```bash
docker compose up -d            # sitio completo local
curl localhost:8000/health      # servicio de trazabilidad
```
